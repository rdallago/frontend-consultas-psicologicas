Sistema de Gestión Psicológica

Bienvenido al Manual de Usuario del Sistema de Gestión Psicológica. Este documento describe las principales funcionalidades del sistema y el procedimiento de utilización de cada uno de sus módulos.

1. Ingreso al sistema

El Sistema de Gestión Psicológica requiere autenticación mediante un nombre de usuario y contraseña válidos. Los datos de acceso deben haber sido registrados previamente por un usuario con permisos suficientes para administrar cuentas del sistema.

Existen tres tipos de usuarios:

  • Administrador: acceso completo a todas las funcionalidades.
  • Profesional: acceso a la gestión clínica y administrativa.
  • Operador: acceso limitado a funciones operativas.

Pasos para ingresar

  1. Abrir el sistema.
  2. Ingresar el nombre de usuario.
  3. Ingresar la contraseña.
  4. Presionar el botón Iniciar Sesión.
  5. Si los datos son correctos se mostrará el menú principal.

Si las credenciales son incorrectas el sistema impedirá el acceso para proteger la información almacenada.

2. Gestión de pacientes

Este módulo permite administrar la información de los pacientes registrados en el sistema.

Alta de pacientes

Para registrar un nuevo paciente debe completarse la información requerida:

  • Nombre.
  • Apellido.
  • DNI.
  • Correo electrónico.
  • Teléfono.
  • Dirección.
  • Fecha de nacimiento.

Una vez guardado el registro, el paciente se incorpora automáticamente al listado general.

Edición de pacientes

Los datos personales pueden modificarse en cualquier momento mediante la opción de edición disponible en la tabla.

Búsqueda de pacientes

La caja de búsqueda ubicada en la parte superior permite localizar pacientes rápidamente. A medida que se escribe, la tabla se actualiza automáticamente mostrando únicamente los registros coincidentes.

Eliminación de pacientes

Por razones de integridad de la información, un paciente solo podrá eliminarse cuando:

  • No posea historia clínica asociada.
  • No posea turnos asociados.

Si existe información vinculada, el sistema impedirá la eliminación y mostrará un mensaje informativo.

3. Gestión de turnos

El módulo de turnos permite organizar y administrar la agenda profesional.

Registro de turnos

  1. Seleccionar una fecha en el calendario.
  2. Seleccionar la hora disponible.
  3. Elegir el paciente correspondiente.
  4. Guardar el turno.

Una vez registrado, el turno quedará asociado al paciente seleccionado.

Estados de los turnos

  • Agendado: turno programado pendiente de realización.
  • No asistió: el paciente no concurrió al turno.
  • Cancelado: el paciente informó previamente que no asistiría.
  • Asistió: estado asignado automáticamente cuando existe una visita asociada.

Identificación visual

  • Azul: Agendado.
  • Naranja: No asistió.
  • Rojo: Cancelado.
  • Verde: Asistió.

Observaciones obligatorias

Los estados No asistió y Cancelado requieren el registro de una observación que justifique la situación.

Restricciones importantes

Cuando un turno posee una visita asociada, el sistema considera que el paciente asistió. En consecuencia:

  • No puede eliminarse el turno.
  • No puede modificarse libremente.
  • Debe eliminarse primero la visita asociada si se requiere modificar el registro.

4. Gestión de visitas

Las visitas representan las entrevistas o sesiones realizadas por el profesional con el paciente.

Nueva visita

Para registrar una visita es necesario seleccionar previamente un turno válido.

El sistema recupera automáticamente los datos del paciente vinculados al turno seleccionado.

Observación clínica

Durante la entrevista el profesional puede registrar información clínica relevante escribiendo directamente o utilizando herramientas de dictado por voz disponibles en el sistema.

Resumen automático mediante Inteligencia Artificial

Una vez registrada la visita, el sistema puede generar automáticamente un resumen clínico utilizando inteligencia artificial.

Este resumen permite sintetizar la información registrada por el profesional y facilitar la posterior elaboración de la historia clínica.

Primera entrevista

Cuando se trata de la primera visita de un paciente, el sistema habilita el registro de información ampliada relacionada con:

  • Motivo de consulta.
  • Antecedentes relevantes.
  • Información inicial de evaluación.
  • Datos necesarios para la confección de la historia clínica.

5. Historia clínica

El módulo de historias clínicas permite gestionar el expediente clínico de cada paciente.

Relación paciente - historia clínica

Cada paciente posee una única historia clínica. La relación entre paciente e historia clínica es de uno a uno.

Creación de historias clínicas

Para registrar visitas es necesario que exista previamente una historia clínica asociada al paciente.

La historia clínica contiene:

  • Paciente.
  • Fecha de creación.
  • Resumen clínico.

Generación automática

El sistema puede generar automáticamente un resumen clínico utilizando toda la información registrada en las visitas del paciente.

El profesional puede revisar, editar y guardar dicho resumen antes de incorporarlo definitivamente a la historia clínica.

Exportación a PDF

Las historias clínicas pueden exportarse a formato PDF para impresión o archivo.

Eliminación

Una historia clínica solo podrá eliminarse cuando no existan visitas asociadas al paciente.

6. Dashboard estadístico

El Dashboard Estadístico proporciona indicadores relacionados con el comportamiento de asistencia de los pacientes.

Indicador principal

El sistema muestra la frecuencia de inasistencias por paciente.

Esto permite identificar rápidamente aquellos pacientes que registran ausencias reiteradas sin previo aviso.

Información considerada

Únicamente se contabilizan los turnos cuyo estado sea:

  • No asistió.

Los turnos cancelados no forman parte de la estadística debido a que el paciente informó previamente su ausencia.

La información se actualiza en tiempo real a medida que se registran nuevos eventos en la agenda.

7. Gestión de usuarios

Este módulo permite administrar los usuarios que tienen acceso al sistema.

Roles disponibles

  • Administrador.
  • Profesional.
  • Operador.

Permisos

Los usuarios con rol Profesional y Administrador pueden acceder a este módulo.

Los usuarios Operador no poseen acceso a la gestión de usuarios.

Administradores

Pueden realizar operaciones de:

  • Alta.
  • Modificación.
  • Consulta.
  • Desactivación y reactivación.

Sobre usuarios Administrador, Profesional y Operador.

Profesionales

Pueden administrar usuarios de tipo:

  • Profesional.
  • Operador.

No pueden administrar usuarios con rol Administrador.

Seguridad de contraseñas

Las contraseñas deben cumplir requisitos mínimos de seguridad establecidos por el sistema.

8. Gestión de respaldos

Este módulo permite realizar copias de seguridad y restauración de la base de datos.

Generación de respaldos

El sistema puede generar archivos SQL que contienen toda la información almacenada.

Restauración

También es posible restaurar la información a partir de un archivo SQL previamente generado.

Acceso

Esta funcionalidad está disponible únicamente para:

  • Administradores.
  • Profesionales.

9. Cierre de sesión

La opción Cerrar Sesión finaliza la sesión activa del usuario.

Una vez cerrada la sesión será necesario volver a ingresar las credenciales para acceder nuevamente al sistema.

Se recomienda cerrar sesión al finalizar el uso de la aplicación, especialmente en equipos compartidos.

10. Preguntas frecuentes

¿Puedo eliminar un paciente?

Sí, siempre que no tenga historias clínicas ni turnos asociados.

¿Puedo registrar una visita sin turno?

No. Toda visita debe estar asociada a un turno previamente registrado.

¿Puedo registrar una visita sin historia clínica?

No. El sistema solicitará la existencia previa de una historia clínica.

¿Por qué no puedo eliminar un turno?

Probablemente el turno tenga una visita asociada. En ese caso deberá eliminarse primero la visita correspondiente.

¿Por qué un operador no ve los módulos Usuarios y Respaldos?

Porque esos módulos están reservados para usuarios con mayores privilegios de administración.

¿Quién puede administrar usuarios?

Los profesionales y administradores.

¿Quién puede realizar respaldos?

Los profesionales y administradores.

¿Puedo imprimir una historia clínica?

Sí. El sistema permite exportar historias clínicas en formato PDF.

¿Puedo imprimir una visita?

Sí. Cada visita puede exportarse individualmente a formato PDF.

¿Qué sucede si olvido mi contraseña?

Debe solicitar a un administrador o profesional autorizado la actualización de su contraseña.
